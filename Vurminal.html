what it is

Vurminal is a terminal receiver that pairs with the Vurminal add-on inside DocuWrite Pro. Instead of an AI deciding what to do, you type slash commands like /wordcount, /inserttext, or /bold, and the add-on runs them against the open document — then sends the results back to the terminal.

Think of it as a shell prompt for your editor. Every command the add-on supports is available, over a peer-to-peer link that needs no server.

setup

Open DocuWrite Pro
Web or installed — either works.
Make sure Add-ons are turned ON
Without this, Vurminal can't load at all.
Open the Add-on Store → find Vurminal
Click Get to install it.
Go to the Library → toggle Vurminal ON
Then launch the editor.
Open the Vurminal receiver
It shows a 6-character peer code at the top.
Paste the code into the sidebar
In the editor, open the "Vurminal" section, paste the code, click Connect.
Type commands
Start with /help to list everything.

features

  • Limitless /click — click any labeled UI control by name. No batches, no cooldown.
  • Peer-to-peer — no server, no account, just a peer code over WebRTC.
  • Full command set — formatting, insert, tables, find/replace, export, page management, and more.
  • Auto-reconnect — if the link drops, the add-on retries up to 3 times.
  • Explore Mode — optionally push a live snapshot of the document into the terminal on each turn.
  • Scope controls — restrict the add-on to specific pages or element types.
  • Download mirror — files exported from the editor appear in the terminal with a save button.
  • Interactive toggles — flip scope, elements, and output options straight from the prompt.

receiver commands

These are typed into the terminal itself, no leading slash:

statusConnection info and current settings.
disconnectDrop the peer link.
vurverShow the Vurminal version.
themeToggle light / dark.
clearAbort the running command and clear the screen.
stopAbort the running command.
toggleInteractive panel of on/off switches.
menuOpen / close the full settings panel.
howtoStep-by-step setup walkthrough.

Add-on commands use a slash: /help, /wordcount, /inserttext, /bold, /click, and about seventy more. The terminal lists everything with /help.
